# La Casita de Balton — Manual de identidad visual

Versión web del manual de identidad visual de **La Casita de Balton**, hogar de rescate y adopción (Córdoba).

Reproduce el mockup del manual pantalla por pantalla: cada sección se recorre hacia abajo, una pantalla completa a la vez, y se pasa a la siguiente con un deslizamiento lateral. Todas las medidas salen del mockup (1 pt del mockup = 1 unidad de la página).

- **Apertura:** portada, consideraciones generales y presentación.
- **01 Rediseño:** análisis de la marca madre, isologotipo, construcción, versiones, reducciones a tamaño real (con calibración de pantalla), normas de uso, alfabetos y colores.
- **02 Sistema:** paleta cromática, marca sobre fondos, iconos, ilustraciones, contenedores y patrones.
- **03 Piezas digitales:** perfil de redes, carruseles de adopción, educativo e informativo, historias y formulario de preadopción, con fichas técnicas cuya escala se recalcula según la pantalla.
- **04 Piezas analógicas:** cartelería y señalética (banner, tambores, espacio, estante y guarda), tarjeta de presentación, indumentaria, stickers, pines, libro para colorear y su versión digital, con sus fichas técnicas; cierra con el colofón.

## Ver el sitio

Es un sitio estático: abrí `index.html` en el navegador o publicalo con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).

Las tipografías (Atma y Nunito Sans, licencia OFL) están incluidas en la carpeta `fonts`; las imágenes están en `img`.
