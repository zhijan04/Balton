# La Casita de Balton — Manual de identidad visual

Versión web del manual de identidad visual de **La Casita de Balton**, hogar de rescate y adopción (Córdoba).

Se lee como un documento editorial: cada sección se recorre hacia abajo y se pasa a la siguiente con un deslizamiento lateral.

- **Apertura:** portada, consideraciones generales y presentación.
- **01 Rediseño:** análisis de la marca madre, isologotipo, construcción, versiones, normas de uso, tipografía y paleta.
- **02 Piezas digitales:** perfil, código cromático, carruseles de adopción y educativo, jornadas, historias y ficha técnica.
- **03 Piezas analógicas:** tarjeta de presentación, indumentaria y ficha técnica.

## Ver el sitio

Es un sitio estático: abrí `index.html` en el navegador o publicalo con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).

Las tipografías (Atma y Nunito Sans) se cargan desde Google Fonts.
